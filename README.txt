ИНСТРУКЦИЯ ПО ЗАПУСКУ И ПРОВЕРКЕ

1. Основной запуск (тесты и замеры производительности):
   python main.py

2. Запуск пошаговой трассировки стека:
   python main.py --trace
   python main.py --trace "{[()]}"

3. Что входит в тесты:
   - Краевые случаи: пустая строка, одиночные скобки '(', ']'.
   - Различные комбинации: вложенные скобки {[()]}, неверный порядок {[(])}, непарные скобки.
   - Строка реального программного кода со скобками.

4. Что показывает замер времени:
   - Линейное время работы O(n) на входах 100 000, 300 000 и 1 000 000 элементов.
   - Сравнение наивного метода O(n^2) и стека O(n) на 40 000 скобок (стек быстрее более чем в 250 раз).
