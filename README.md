# Проверка корректности скобочной структуры

Реализация алгоритма проверки скобочной структуры трех видов (`()`, `[]`, `{}`) с использованием стека (Вариант 1).

## Требования
- Python 3.8 или выше.
- Дополнительные библиотеки не требуются (используется только стандартная библиотека).

## Инструкция по запуску

### 1. Основной запуск (тесты и замеры)
Запуск тестов корректности и измерение времени работы:
```bash
python main.py
```
или
```bash
python3 main.py
```

При запуске программа автоматически выполняет:
1. **Тестовые запуски** — проверка корректности работы алгоритма, включая краевые случаи (пустая строка, одиночные скобки, непарные скобки, код со скобками).
2. **Замер времени** — измерение времени выполнения алгоритма на стеке на нарастающих объемах данных (100 000, 300 000, 1 000 000 элементов) с усреднением по 5 запускам.
3. **Сравнение решений** — сравнение времени работы наивного алгоритма (удаление подстрок $O(n^2)$) и алгоритма на стеке ($O(n)$) на одном размере входа (40 000 скобок).

### 2. Пошаговая трассировка работы стека
Для наглядного вывода состояния стека на каждом шаге запустите:
```bash
python main.py --trace
```

### 3. Проверка своей строки
Вы можете передать любую строку аргументом в команду:
```bash
python main.py --trace "{[()]}"
python main.py --trace "{[(])}"
```

## Структура проекта
- `main.py` — основной файл с реализацией функций проверки, трассировки и замеров.
- `README.md` — инструкция по запуску и описанию тестов.
